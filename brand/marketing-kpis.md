# Marketing KPIs — Framework Only

No baseline numbers are invented. Fill values only from verified analytics exports or ChatGPT Work reports.

## Suggested KPI families

### Awareness / reach
- Page reach
- Post impressions
- Video/photo views (if applicable)

### Engagement
- Reactions, comments, shares
- Engagement rate (define formula when data exists)
- Reply speed for inbound comments / DMs (manual ops)

### Group opportunity quality (research KPIs)
- Count of High/A scored Delta groups
- % of scored groups with verification source
- Geo coverage across stated Delta cities

### Conversion proxies (UNKNOWN until measured)
- Inbox inquiries
- Order intents from comments
- Landing / catalog clicks — UNKNOWN if unused

### Paid (if used later)
- CPA / ROAS — UNKNOWN until ads data available
- Use `ads` / `ad-creative` skills for planning only

## Rules

1. Prefer `goals-and-kpis` + `analytics` + `analytics-and-reporting` skill methods.
2. Never fabricate week-over-week lifts.
3. ChatGPT Work owns recurring performance reports; this file defines definitions.
