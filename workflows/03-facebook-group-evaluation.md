# Workflow 03 — Facebook Group Evaluation

## Purpose

Score Facebook Groups for Beity Store opportunity using the Delta methodology.

## Inputs

- `brand/group-research-methodology.md`
- `evidence/groups-snapshot/beity_177_groups.csv`
- Optional shortlist from ChatGPT Work

## Skills to invoke

1. `facebook-groups`
2. `community-marketing`
3. `competitor-analysis` (for competitive group presence signals if evidenced)

## Steps

1. Apply the A/B/C + 0–5 rubric from the methodology file.
2. Prefer Delta geo + household category fit.
3. Keep verification source column visible in the output table.
4. Flag policy risk; do not recommend bypasses.

## Guardrails

Do not join groups, scrape private content, or publish. Evaluation only.

## Outputs for ChatGPT Work

- Scored group table (name, URL, region, type, score, band, rationale, citations)
- Top opportunities shortlist
- Watchlist / reject list
