# Workflow 01 — Facebook Marketing Strategy

## Purpose

Produce a Facebook-first strategy brief for Beity Store without publishing or inventing metrics.

## Inputs

- `brand/brand-profile.md`
- `brand/facebook-strategy.md`
- `brand/audience-profile.md`
- `brand/marketing-kpis.md`
- Any user goals for the period

## Skills to invoke (do not duplicate)

1. `product-marketing`
2. `facebook-strategy`
3. `social-strategy`
4. `goals-and-kpis`

## Steps

1. Load brand files; list UNKNOWN gaps.
2. Apply `facebook-strategy` + `social-strategy` for Page + Groups role definition.
3. Apply `goals-and-kpis` for KPI definitions only (no fake baselines).
4. Output a strategy brief for ChatGPT Work.

## Guardrails

Never publish, join groups, like, comment, or mass-DM. Never invent sales/follower numbers.

## Outputs for ChatGPT Work

- Strategy summary (Page vs Groups)
- Priority themes
- KPI definition table with blanks for real data
- Evidence citations + UNKNOWN list
