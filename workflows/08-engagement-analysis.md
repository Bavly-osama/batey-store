# Workflow 08 — Engagement Analysis

## Purpose

Analyze engagement patterns from user-provided exports/screenshots and recommend experiments.

## Inputs

- Page insights exports or screenshots (user-supplied)
- Post URLs with observable public metrics
- `brand/marketing-kpis.md`

## Skills to invoke

1. `analytics-and-reporting`
2. `content-audit`
3. `experimentation-and-ab-testing`

## Steps

1. Inventory available metrics; reject invented numbers.
2. Audit top/bottom posts for format, hook, offer clarity.
3. Propose A/B tests with hypothesis + success metric.
4. Package findings for ChatGPT Work evening/daily reporting systems (do not create a parallel report cadence here).

## Guardrails

No fabricated lifts. No automated engagement actions (like/comment).

## Outputs for ChatGPT Work

- Engagement findings memo
- Content audit table
- Experiment backlog
