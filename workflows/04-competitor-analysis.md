# Workflow 04 — Competitor Analysis

## Purpose

Build dated competitor profiles for Facebook household sellers relevant to Beity Store / Delta.

## Inputs

- `brand/brand-profile.md`
- Competitor Page/group URLs supplied by user or evidenced publicly
- Optional screenshots/exports

## Skills to invoke

1. `competitor-analysis`
2. `competitor-profiling`
3. `competitors`

## Steps

1. Confirm each competitor source is public and cited.
2. Profile offers, messaging, content formats, CTA style — only what is visible.
3. Note gaps vs Beity Store without inventing Beity metrics.
4. Separate facts vs inferences.

## Guardrails

No private data access. No impersonation. No unauthorized scraping.

## Outputs for ChatGPT Work

- Dated competitor profile cards
- Comparison matrix (features/messaging only)
- Opportunities / risks with citations
