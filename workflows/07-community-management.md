# Workflow 07 — Community Management

## Purpose

Draft community response playbooks for Page comments, group discussions, and sensitive cases.

## Inputs

- `brand/brand-voice.md`
- Comment/DM scenarios from user or ChatGPT Work
- Escalation preferences from user

## Skills to invoke

1. `community-management`
2. `engagement-routine`
3. `crisis-and-moderation`
4. `social-selling-and-dm`
5. `reply-and-comment-writer`

## Steps

1. Classify scenario: routine Q&A, sales intent, complaint, crisis, spam.
2. Draft reply options in Egyptian Arabic.
3. For DMs: provide human-send scripts only — no bulk automation.
4. For crisis: escalate guidance; do not invent legal/refund policy.

## Guardrails

Never auto-reply, never mass-DM, never join/moderate groups autonomously from this workspace.

## Outputs for ChatGPT Work

- Response macros by scenario
- Escalation checklist
- Do/Don’t community rules aligned to unknowns (no fake policies)
