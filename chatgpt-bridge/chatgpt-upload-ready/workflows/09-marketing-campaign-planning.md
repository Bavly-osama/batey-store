# Workflow 09 — Marketing Campaign Planning

## Purpose

Plan a time-bound Facebook campaign (organic and optional paid) for Beity Store.

## Inputs

- Campaign objective from user / ChatGPT Work
- `brand/*` context
- Budget / dates if provided (otherwise mark UNKNOWN)

## Skills to invoke

1. `marketing-plan`
2. `marketing-ideas`
3. `marketing-psychology`
4. `ads` (if paid is in scope)
5. `ad-creative` (if paid creatives needed)
6. `content-calendar` (for organic sequence)

## Steps

1. Clarify objective, audience, offer facts (block if offer facts missing).
2. Build campaign phases and creative angles.
3. Separate organic vs paid workstreams.
4. Define measurement using KPI frameworks without fake baselines.

## Guardrails

No publishing. No launching ads from this workspace. No invented discounts.

## Outputs for ChatGPT Work

- Campaign brief
- Creative angle list
- Organic calendar scaffold
- Paid plan stub (if applicable)
- Risk / compliance notes
