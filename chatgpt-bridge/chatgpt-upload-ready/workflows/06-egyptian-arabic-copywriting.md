# Workflow 06 — Egyptian Arabic Copywriting

## Purpose

Draft Facebook-native copy in Egyptian Arabic aligned to brand voice constraints.

## Inputs

- `brand/brand-voice.md`
- `brand/brand-profile.md`
- Product facts supplied by user (required for prices/offers)
- Creative brief / pillar from content strategy

## Skills to invoke

1. `copywriting`
2. `writing-style-and-tone`
3. `hook-writer`
4. `caption-writer`
5. `reply-and-comment-writer` (when drafting comment replies)

## Steps

1. Confirm product facts; refuse to invent prices/stock/offers.
2. Draft hooks + captions in عامية مصرية.
3. Provide optional MSA variant only if requested.
4. Validate length/format against `platform-specs-and-validation` when publishing specs matter.
5. Label drafts as **drafts for human approval**.

## Guardrails

No auto-posting. No spammy ALL-CAPS hard sell. No fabricated testimonials.

## Outputs for ChatGPT Work

- Hook options (3–5)
- Full caption draft(s)
- CTA variants
- Facts used + UNKNOWN blockers
