# Workflow 10 — Marketing Performance Analysis

## Purpose

Turn verified performance data into decision-ready insights for ChatGPT Work (not a recurring report engine).

## Inputs

- User-supplied analytics exports
- Prior campaign briefs
- `brand/marketing-kpis.md`

## Skills to invoke

1. `analytics`
2. `analytics-and-reporting`
3. `goals-and-kpis`
4. `content-audit`

## Steps

1. Confirm metric definitions and date range.
2. Compare results vs stated goals (not invented targets).
3. Attribute insights only where evidence supports.
4. Recommend next actions / experiments for ChatGPT Work owners.

## Guardrails

Do not schedule recurring daily/evening reports inside Claude Code. Do not invent missing metrics.

## Outputs for ChatGPT Work

- Performance insight memo
- KPI scorecard (blank cells for missing data)
- Prioritized recommendations with citations
