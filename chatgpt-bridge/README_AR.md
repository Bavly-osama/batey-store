# جسر ChatGPT ↔ مساحة التسويق المحلية

## الفكرة
مفيش بلجن رسمي يخلّي Claude Code وChatGPT يتكلموا لوحدهم على جهازك.

اللي اتعمل بدل كده = **جسر عملي**:
1. ملفات معرفة جاهزة للرفع على ChatGPT Project / Custom GPT / ChatGPT Work
2. تعليمات نظام (`01_SYSTEM_INSTRUCTIONS.md`)
3. ZIP جاهز: `Beity-ChatGPT-UploadPack.zip`
4. الشغل التنفيذي المحلي يفضل في **Cursor** على نفس المجلد

## خطوات الربط (مرة واحدة)

1. افتح المجلد:
   `X:\Beity-Store-Marketing-Agent\chatgpt-bridge\`
2. فك أو استخدم `Beity-ChatGPT-UploadPack.zip`
3. في ChatGPT:
   - اعمل **Project** اسمه `Beity Store Marketing`
   - انسخ محتوى `01_SYSTEM_INSTRUCTIONS.md` في **Instructions**
   - ارفع باقي الملفات في **Project files / Knowledge**
4. خلاص — أي شات جوه الـ Project ده يبقى مربوط ببراند بيتي ستور

## دورة الاستخدام اليومية

```text
Cursor (محلي)
  → مسودة / تقييم جروبات / كابشن
  → تنسخ الناتج

ChatGPT Project
  → تقرير مسائي / قرار / توصية بيزنس
```
